PROJECT INFORMATION

About & Sources

Project purpose, source references and data limitations.

Project purpose

Mars Explorer combines planetary map context, mission references, imagery search, simulated route sketches and researcher notes in one educational workspace.

Planned data sources

  • NASA Mars Trek WMTS documentation
  • NASA Image and Video Library
  • NASA Planetary Data System
  • USGS Astrogeology

Data integrity & safety

  • Every scientific layer needs source, product name, date, coverage and coordinate reference system.
  • Historical measurements must not be labelled as live conditions.
  • Unavailable measurements must remain marked unavailable.
  • Route distance is not a safe or optimized rover path.
  • This is not an operational navigation or safety system.

Current map art is synthetic. NASA images are retrieved through the public Image and Video Library API. The retired Mars Rover Photos API is not used.
